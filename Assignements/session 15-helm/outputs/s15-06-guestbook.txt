########## Deploying an application: guestbook chart (lint, install, upgrade, rollback) ##########
$ helm lint 09-deploying-application/guestbook-chart

1 chart(s) linted, 0 chart(s) failed

$ helm install guestbook 09-deploying-application/guestbook-chart --set image.tag=1.27 --wait --timeout 180s | grep -E '^NAME|^STATUS|^REVISION'

STATUS: deployed
REVISION: 1

$ (upgrade: change the ConfigMap values)
$ helm upgrade guestbook 09-deploying-application/guestbook-chart --reuse-values --set config.welcomeMessage='Welcome from Kiran N - Roll No 10446' --set config.appName='Kiran Guestbook' --wait | grep -E 'upgraded|^REVISION'
Release "guestbook" has been upgraded. Happy Helming!
REVISION: 2

$ kubectl get configmap guestbook-config -o jsonpath="{.data}{\"\n\"}"
{"appName":"Kiran Guestbook","welcome":"Welcome from Kiran N - Roll No 10446"}

$ (the running pod still has the OLD values: env from a ConfigMap is read only when the container starts)
$ kubectl exec deploy/guestbook-app -- printenv welcome appName
Welcome to the Guestbook!
My Guestbook

$ kubectl rollout restart deploy/guestbook-app && kubectl rollout status deploy/guestbook-app --timeout=120s
